# 动画裁切修复 v0.2.1

用户报告 Grok 头发重复、Claude 左右显示不完整。逐格隔离原始图集后复现：部分瑕疵已经存在于单格内部，不是把截取框加宽就能修复。原图尺寸均为1536×2288，8列11行，单格192×208。

## 修改

- 用固定 SVG viewBox 单格窗口代替背景百分比位移。保持原格宽高比，裁切独立于页面宽度和缩放。
- `src/shared/animation.ts` 保存逐角色、逐动作的可用帧序列。Grok 等待行与部分思考帧排除；Claude 等待、审阅行有明显平直裁断，改用完整抱书帧。
- 检查其余四套图集，排除 DeepSeek、GPT、Kimi 中确认有残片/截断的部分帧。Gemini 暂未发现相同问题。
- 不修改原始素材字节和来源清单。部分动作共用完好序列，配合原动作位移和情绪效果；不宣称修复了原图中不存在的头发。

## 验证

- 19项逻辑测试，包括已知坏帧不进入循环、各动作仍有多帧。
- `node --import tsx scripts/verify-sprites.mjs` 在真实 Electron 窗口观察 Grok / Claude 动作循环，并把生产 SVG 与独立 canvas 原图裁切进行45次像素透明度比较，覆盖100%、125%、150%缩放。
- `test-results/sprites-fixed.png` 为人工检查过的候选帧预览。实际桌面、私聊及重启恢复另由桌面冒烟测试覆盖。

本修复处理已复现的裁切和残片问题，不保证生成式图集每一帧的五官、比例完全连续。
