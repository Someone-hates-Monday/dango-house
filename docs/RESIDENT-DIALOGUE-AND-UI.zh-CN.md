# 各自说话、明确对象与轻松争宠

版本：0.5.0-alpha.11，2026-11-16。

## 用户能看到的变化

- 每位角色有自己的近期气泡，标题标出「说话者 → 对象」，当前说话者和听话者有不同提示。对用户、对某位同伴、对大家不再混为一谈。
- 点击气泡打开对应公开或私聊记录，并定位该条消息；只是阅读，不触发新的剧情。私聊不会泄露到公开记录。
- 气泡使用固定上方空间，按位置避让；旧气泡淡化、过期消失。CG 期间隐藏气泡，结束后不重播旧台词。多人 CG 依旧只播放一份。
- 屋檐按钮改为图标，吊绳接在屋檐下；保留悬停说明、可访问名称和置顶状态。设置导航紧贴滚动区域顶部，背景完整覆盖；在场名单显示实际角色头像。

## 模型与调度约定

每句模型对白携带 `audience`（`user`、`companions`、`group`），对特定同伴发言时携带 `replyTo`；同一场景共享 `sceneId`。这些信息经过解析、队列、移动到达、最终消息记录完整保留。一句只对一个对象说，转向用户时另起一句。上下文也传入此前的对象，提示模型先回答问题、承接眼前话题，再发展情节。

「轻松争宠」可独立关闭，和女孩子之间的贴贴、剧情短片开关分开。夸奖、选中私聊或连续亲昵互动可邀请另一位角色向用户表达想被关注；不强制双人恋爱或 CG，不以责怪用户收尾。争宠必须有另一位实际对用户说话，光对被夸的人打趣不算完成。冷却从真正发出的台词开始，取消的场景不消耗冷却。

修复了一个真实 API 问题：非聊天事件输出了多余的非标准 `focus`，旧解析器会拒绝整段计划。现在此类事件采用事件本身的固定对象，忽略无关标签；公开聊天仍验证有效枚举。必要接话缺失时只做一次有界模型修正，不插入固定补台词。

## 验证与接手注意

- 163 项单元测试涵盖公开/私聊隔离、布局避让、移动到达对象信息、争宠开关、实际发言冷却和解析修复。
- `scripts/verify-resident-dialogue.mjs` 使用隔离存档和本地模拟 API，验证真实渲染/IPC、对象标识、听话提示、无重叠、阅读不触发模型、争宠开关和零原生窗口尺寸变化。支持 `--packaged`。
- 已通过真实 DeepSeek 检查：Claude/DeepSeek 问答承接、另一位向用户争取关注、GPT 私聊对象隔离。生成模型仍可能偶尔表达生硬，不能保证每次台词都完美。
- 原始界面截图和测试报告在忽略目录 `test-results`。正式 GPT 视频资源未替换。
- 实际用户存档已恢复核心三人、360×300 小屋。以后全员测试用隔离存档；不能在恢复逐个在场状态后再次应用不匹配的 `all` 预设，否则会重新扩为七人并改变窗口大小。不要改写用户密钥或删除可见历史。

源码与本地打包版本的验证结果见本次交付；公开 GitHub Release 独立管理，不因本地版本更新自动发布。
