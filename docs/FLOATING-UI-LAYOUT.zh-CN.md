新增共享屏内布局计算，Dock/自由桌宠/小屋启用：菜单优先，CG其次，气泡在剩余位置摆放；工具栏和角色占用区域纳入避让。菜单限制在视口内并可滚动，同一渲染窗口仅展开一个桌宠更多菜单。Dock只在鼠标、焦点或展开菜单时显示工具栏，播放反应本身不再让多条工具栏叠起来。
