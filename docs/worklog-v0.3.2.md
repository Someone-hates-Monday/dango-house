# 本轮事项及验收顺序

按用户提出顺序收尾；后续新反馈追加到末尾，不跳过当前事项。一次发布包含已通过验收的修复。

1. **DS 制作流程核查：已完成。** 原项目及当前引用提交均明确：豆包整段生成，10 秒绿幕视频，发布动作全部采用 Premiere 手工抠像，统一尺寸及脚底线后转为 VP9 alpha WebM。确切模型版本、seed 和重试次数未披露。原脚本已存入 `.animation-lab/dsh-source/`，Claude 三动作试制配方见 `animation-lab/dsh-reproduction.json`。这里完成的是流程核查与试制准备，没有把豆包生成标为完成，也没有声称可自动将 DS 视频换成别的角色。
2. **角色横条：已修复、已验证。** 原 RigSprite 将纹理拆成每 8px 一条后分别作浮点变形，存在过滤接缝与横向断层风险；现在每层纹理一次连续绘制，保留呼吸、倾斜、关键姿态、抚摸及投喂。七位趴姿和站姿都不再使用切条绘制。
3. **Dock 悬空、漂移：已修复、已验证。** 校准四个图集趴姿的实际接触线到画布 y=220，保留另三个独立趴姿；CSS 以接触线对齐工作区底边。移除位置正弦漂移和插值追逐，趴下时取消整体浮动与旋转。125%/150% 缩放下七位接触线误差小于 1 CSS px，悬停及互动均不改变槽位。
4. **站立动作及难点按钮：已修复、已验证。** Dock 不再强制站立 DS 使用图集；站起后复用自由形态的 Sprite、互动元数据和停止状态，仅消除位移/原地空跑。动作执行时保持站立，DS 留足整段视频播放时间。工具栏五个按钮各 32px，人物到工具栏有连续命中区域，悬停期间不消失。自动化真实点击已验证抚摸→shy、投喂→rice、挥手→wave 及其视频播放、打开并关闭私聊；其余六位 read 指令能进入相同的自由形态渲染路径。实际 v0.3.2 打包资源也通过该验证。

验证脚本：`scripts/check-dock-render.mjs`（两种 Windows 缩放、接触线、槽位、画布命令、真实工具栏点击、视频播放与动作切换）、`scripts/verify-v03.mjs`（场景/趴站/私聊/透明立绘/摔倒恢复）、`npm test`。打包后用前者加 `--packaged` 再检验实际发布包。
