# Privacy

**Language / 语言 / 言語:** [简体中文](PRIVACY.zh-CN.md) · [English](PRIVACY.en.md) · [日本語](PRIVACY.ja.md)

Dango House keeps chat, memories, relationship settings, and UI language on this Windows user profile (`%APPDATA%/Qiting`). API keys are encrypted with Electron `safeStorage` and are never required in chat.

Live model requests send the current channel context, character prompts, and relevant house state to the provider you chose. Watch-party media stays in a local media cache unless you later enable an explicit cloud vision path.

You can clear group chat, delete memories, and remove saved keys from Connections & Preferences. Do not paste keys into issues or screenshots.
