# v0.2.2：安静陪伴、完整动作与适度重叠

## 节奏与站位

- 普通待机主要停留，约12秒一次短暂眨眼。挥手、开心、害羞等事件动作播放一轮后停留；行走只在移动期间循环。
- 去掉额外循环摇摆和蹦跳。闲置小屋活动从约9秒一次改为约60秒一次，以看书、照顾植物、坐下为主；自动群像剧情约3分钟以上间隔。主动点播不受此间隔限制。
- 小屋与桌面共用站位约束：不仅限制两两重叠，还限制其他角色占位矩形的合并遮挡面积，不超过每位角色占位面积的一半。走向伙伴、聚在家具旁、拖动和缩放均应用约束。占位框包含透明留白，因此视觉上更保守。
- 原始角色位置保留，显示时选择附近空位；拖动松手保存调整后的桌面位置。安静状态缓存布局，避免反复求解。

### Claude 生成提示词

内置 imagegen；transparent_background=true；输入 `public/animated/claude.webp`（编辑目标与风格）、`public/community/claude/idle.webp`（完整形象参考）。

> Use case: precise-object-edit. Asset type: repaired animation sprite strip for an existing noncommercial desktop companion. Image 1 is the edit target / identity and style source: the orange-haired flower-adorned book-holding chibi Claude sprite atlas. Its seventh row (waiting, row index 6) contains six frames whose hair/body have straight cut-off boundaries. Image 2 is supporting full-character reference only, showing complete orange long hair, flower hair clip, cream and brown scholar maid dress, shoes and book. Repair and complete those six waiting/shy poses as ONE transparent sprite sheet with exactly 3 equal columns and 2 equal rows, no text, no labels, no grid lines. Each cell contains ONE full-body character, all six matching the same original chibi proportions, face, clothing details and color palette. Keep the character identity and clean anime sprite rendering from image 1. All hair, ribbons, dress, hands, shoes must be complete with natural curved edges, no duplicated hair fragments and no straight clipping. Sequence in reading order: neutral waiting holding book against chest; slight head tilt and attentive eyes; small shy smile with book lifted a little; gentle blink, eyes closed; eyes reopen, subtle blush; return smoothly to first neutral waiting pose. This is subtle, slow meaningful animation, not six unrelated poses, not bouncing. Fixed camera, exact same scale and feet baseline within each cell, body centred, with at least 12% transparent padding on every side inside every cell. Prefer a 1536 by 1024 canvas, 512 by 512 per cell. Do not flatten or squash the character, crop any hair, add extra limbs, add backgrounds, or paste neighbouring sprites. Preserve genuine alpha transparency.
