# 模型 ID 与设置页

模型 ID 是服务商 API 使用的模型名称，不是角色名字。核对日期：2026-11-15，来源为 [DeepSeek 官方接入文档](https://api-docs.deepseek.com/)。

使用 DeepSeek 官方 API 时，服务商选 DeepSeek，完整地址填 `https://api.deepseek.com/chat/completions`，日常陪伴可先填 `deepseek-flash`，另一官方选项是 `deepseek-v4-pro`。设置页的示例按钮只填写输入框，不会自动保存配置或发送付费请求。第三方中转需要使用其控制台显示的地址和模型 ID。

填写后保存并测试连接，再启用真实聊天。工具调用开关用于允许模型控制人物动作；不支持工具的模型可以关闭后测试普通聊天。API Key 仅在本机应用输入。

0.4.0-alpha.6 修复设置页复选框被文本输入框的整行样式拉宽、文字与控件分离的问题。复选框 20×20，整行勾选区域至少 44 像素高；开关点击区域 52×44；正文控件 14–15px、说明 13px。说明靠近对应控件，按钮组支持换行，选用的服务商在打开设置时保持不变。

验证脚本：`node scripts/verify-settings-layout.mjs --packaged`，使用隔离离线存档，覆盖 1280×860 / 1060×760、中英日文、点击文字勾选、模型示例填写、控件大小与页面横向溢出，不发送真实 API 请求。GPT 动画保持 alpha.5 的清理版。

当前本机包为 alpha.6；公开预发行下载仍为 alpha.5。本轮不覆盖已发布的二进制。
