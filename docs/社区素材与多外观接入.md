上游智谱的造型与 CrossPet 黑狐版本不同，不应只因名字相同就当作同一套外观。后续会在外观条目上标注创作版本，避免混淆。

## 外观系统的实施原则

1. **角色身份与外观分离。** 角色定义、人设、群聊 ID、关系和记忆不随换皮重建。
2. **每个外观独立登记。** 记录作者、原作版本、来源、许可、渲染方式、动作映射、比例和默认尺寸。
3. **同一业务状态多种表现。** idle、talk、focus、happy 等状态映射到表情图、精灵帧、Live2D 动作或其他渲染适配器。
4. **仅启用实际可用的选项。** 找到参考不等于模型已经下载、动作齐全或应用支持；未完成的类型在资料页说明，不做虚假的可选项。
5. **按角色独立选择。** 当前已实现三位角色各自选择两套 Q 版；用户可混搭，日后增加统一切换全员风格。

后续顺序：先扩展 Q 版动画覆盖七位，再验证一个 DeepSeek Live2D 完整闭环；正常比例与像素资源根据实际可用度加入。不会因为产品支持四种渲染类型，就宣称所有角色都已拥有四套齐全素材。
