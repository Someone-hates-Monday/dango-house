# 从聊天到同伴演出、自己玩与对白去梗化 · 0.5.0-alpha.10

## 可以这样使用

- 公共聊天或 Claude 私聊：“Claude，怎么不找大肥鱼玩？去找她待会儿吧，我想看你们亲近。”
- “我有些事情要忙，你们自己玩吧，不用一直找我。”
- “我忙完回来了，陪我聊聊今天开心的事吧。”

角色接受邀请时，不再只用文字描述：实际走近、伙伴接话、配合 Q 版动作，情境合适时播放一份共享 CG。不是每句话都强制触发 CG；参与者、亲密偏好、自动播放开关和冷却时间继续有效。未开启形象工具时，私聊不会获得邀请工具。持续自主相处仍遵守主动互动设置、静音、免打扰、场景优先级及现有调用频率限制。

## 如何串起来

公共消息由模型根据语义选择 `focus:user` 或 `focus:companions`，可理解间接的“怎么不去找她玩”，而不是要求用户说出技术关键词。普通摸头、投喂仍固定面向用户，不能靠输出 `focus:companions` 擅自改成两人亲密戏。

接受邀请后的计划包含短暂回应、`approach` 的精确同伴目标，或两人的共同 `gather` 目的地，再接伙伴对白与表情动作。实际行走沿用安全路径与到达后发言；已经靠近、没有可用路线时不原地跑步。场景完成后才启动 CG，沿用小屋上方的一份播放层，不在两人头上复制视频。

私聊新增 `invite_companion` 工具。角色先决定发出邀请，提交在场伙伴 ID 与可公开的简单目的；先完成当前私聊回复，再启动共享拜访场景。不能将“已排队”说成“已到达”。私聊正文、私事和完整上下文不会自动传给公共场景；只有角色主动提交的公开邀请主题会进入共享规划。工具调用仍需模型遵守公开主题指引，不应把这当成文本内容的完美隐私分类器。

停止、切换任务或取消正在生成的回复后，未完成邀请不会延迟偷跑；角色缺席或静音时不能被邀请。每轮最多一次邀请。OpenAI 兼容接口与 Anthropic 工具流都受支持。

## “你们自己玩”不是拒绝用户

模型可在明确的用户意图下更新 `housePlayMode:self-play`，在用户回来时设回 `together`。状态保存到本地，小屋底部显示“她们自己玩”。自主场景只读取偏好，不能自行改写用户状态；不会把让她们玩理解为冷落、催用户回来，或反复以“只想陪你”为由拒绝找伙伴。

你主动说话或触碰时仍能得到回应。该状态引导后续自主事件更多围绕伙伴相处，而不是强行永久切断用户交流。主动互动设置关闭时，明确邀请仍能执行一场，之后不会偷偷打开自动闲聊。

## 为什么只改人设仍然爱提书

实测发现：即使简化新指引，旧私聊和共同事件里的大量“合书、放下书、别碰书”仍会被模型模仿。全套外观设定、旧示例、历史旁白和固定 CP 情节重复强调同一物件，会持续强化它。

这次将模型用的口语人设与完整视觉设定分开。角色图像、Q 版动作及完整定义继续保留；口语卡以性格、措辞、关心方式与昵称为主。七位角色的示例统一检查并替换为不强塞道具的短句：不再默认要求 Claude 提书、DeepSeek 提饭、GPT 提尾巴、GLM 算钱、Kimi 提月光等。道具和兴趣可以出现在真实相关的话题与动作中，不是禁用这些词。

新生成的角色消息标记 `voiceRevision:2`。模型默认上下文从新版对白开始，不再回放旧版角色逐字台词；还没有新版对白时先回应当前用户消息。共同事件给出参与者和触发类型，而不再次注入旧台词。**可见聊天记录没有删除，明确记忆、关系、API 配置与存档保留。** 旧版逐字聊天不再是默认生成上下文，重要的长期事实仍应保存在明确记忆中。

私人输出只说角色的话，动作交给工具。当前实际输入单独强调，已完成的旧邀请不应在无关新话题里反复续提。Grok 的玩笑也调整为和用户站在一起，而不是给用户的小成就评定是否值得开心。

## 验证与接手点

- 156 项单元测试与生产构建：语义场景选择、触摸边界、真实移动、场景完成后 CG、私聊邀请、停止后的旧任务失效、私聊隔离、相处状态持久化、两种工具流、新旧语气上下文及七位角色示例。
- `scripts/verify-companion-handoff.mjs`：公开和私聊两条真实渲染器／IPC／本地 SSE 路径，实际靠近、同伴模型回复、自己玩状态、一份共享 CG 和私聊隔离。另回归悬停反馈，保留上一版修复。
- 保存的 DeepSeek 连接实测：普通单聊、私聊邀请、实际同伴接话与走近、合适的 CG、“你们自己玩”、用户回来切回一起聊。早期仍复读书本，完成上下文迁移后 Claude 的这些样本未再提书。
- 七位角色各一次真实普通对白抽查，随后对 Claude 与 Grok 定向复测。Claude 不再在日常分享里接旧的同伴邀请；Grok 的复测没有给用户成就打分。一次 GLM 样本仍自然提到尾巴，说明这是降低固定梗密度，而不是词语封禁或完美保证。

实际对话和密钥只用于本机检查，没有提交仓库。隔离检查最初点击到了重叠区域、随后还遇到两人已靠近的情况；改为真实可点击区域和检查任一参与者的实际移动，未用强制点击或凭空要求已相邻者再跑一圈。

主要入口：`src/shared/house-events.ts`、`src/shared/companion-voice.ts`、`src/shared/dialogue/voice-examples.ts`、`electron/avatar-tool.ts`、`electron/provider.ts`、`electron/engine.ts`。以后补新动作或 CG 时，扩展可执行能力与合适场景，不再靠追加固定嘴硬台词模拟人设。

本机桌面与源码更新到 0.5.0-alpha.10；公开 Release 单独发布。视频素材和原生窗口尺寸机制未改动。
