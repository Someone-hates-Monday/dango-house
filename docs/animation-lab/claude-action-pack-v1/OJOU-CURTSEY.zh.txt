# 大小姐行礼（标准脚法）— 可嵌入各条提示词

用户校正（2026-11-06）：不是「左脚往左撤」或任意脚往后撤半步。

## 正确体态（正面观众时）

1. **左脚**基本留在原地作支撑（可微屈膝）。
2. **右脚**从左脚**后方**向画面左侧划出一小步（右脚尖落到左脚左后方，两脚成小交叉/错步，不是平行后撤）。
3. **同时**：空出的手（或单臂托书时的右手）轻轻捏起自己裙摆外侧一角向身侧略提（提裙）；头向前轻点一次致意；躯干略前倾。
4. 抱书时：书始终由另一臂抱稳或夹在臂弯，禁止双手同时离书乱提裙导致书悬空消失。
5. 收势：右脚收回与左脚并立，裙放下，头抬回，书回胸前。

## 可直接粘贴的演出句

```text
大小姐行礼：左脚原地支撑并微屈膝；右脚从左脚后方朝画面左侧轻撤半步落在左脚左后方（交叉错步，禁止左脚外撤、禁止双脚平行后跳）；同时右手（或空出手）轻提自己裙摆外缘，头向前轻点致意，躯干略倾；书由左臂抱稳不离身。然后右脚收回并立，放下裙摆，抬头回正。
```

## 禁止

- 左脚往左边撤 / 随便哪只脚往后蹬
- 只点头没有脚和提裙
- 深跪、女仆大屈膝拖地礼（本角色是大小姐轻礼，不是跪拜）
- 提裙时书掉到地上或瞬移消失
