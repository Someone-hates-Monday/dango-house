# GPT 基础参考修订：先消除歧义，再生成动作

## 需要改什么

不是只在上方“删一个尖”。旧正面图尾根被裙发遮住，身侧粗弧与脚边细尖难追踪；旧结构图又向侧上方展开，文字要求低位却给出相反像素。先让基础图自身成立，再谈辅助参考数量。

1. **新正面/微侧首帧**：角色面向用户，身份、头身比例、衣装与现用Q版一致。尾根仍从骨盆后方连接，在身体侧露出可辨粗段；中段向下形成开放而不自交的小C弯；唯一细尖在脚踝外侧稍离裙鞋轮廓，留小段背景间隙。不要贴成粗团、把尖藏在裙边、增加末端饰物或改变物种。只调整尾部可读性及必要的自然发丝遮挡，不为露根挖裙洞或改变服装结构。
2. **三分之四背侧结构图**：同一套角翼、发饰、衣装、尾长与鳞片。尾根在翼根下、骨盆后，不接在背中/裙摆；发丝自然分到侧边，清楚展示接点。尾身连续变细，尾尖低位。此图仅解释连接，不要求成片背向用户或转身。
3. **可选正侧图与人审标注图**：明确root→tip和遮挡顺序。标注只供审核，生成版去掉文字箭头，避免烧入画面。看不见的结构只能标设计推断，不能声称来自原作者设定。

## 静帧门槛

- 不读提示词也能指出同一条尾的根与唯一尖；根粗、尖细，中间可连续追踪。
- 正面/背侧尾根高度、长度、转折与配饰互相一致；不是两张不同龙娘图拼起来。
- 全身留边，角翼尾鞋完整；尾尖与鞋裙分离可辨，没有通过藏尾规避。
- 把新图与现用idle/P1并排，核对面部、体型、脚底、角色尺度和尾型；新图是候选，不自动替换已采用片。

建议先从原身份锚点编辑尾部，避免重新生成整个人。若需生成背面，按同一角色图编辑而非无参考新画；每张记录输入图与版本，结构检查不过就停在静帧。用户没有要求本轮立即生成，本文只记录方案。
