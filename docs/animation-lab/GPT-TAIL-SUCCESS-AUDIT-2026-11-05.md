# GPT 尾巴：现用两片与 Cursor D1 对照

2026-11-05。已读生产 manifest、原 generation.json、PixVerse 提示词与 Cursor 纠错方案，目视对照原始待机 anchor、P1 首尾图及 greeting-D1 六时点接触表。本轮未完整逐帧重审全部原片，不把正面遮挡造成的视觉歧义直接判为三维根尖交换。

## 现用两次究竟怎么做

**待机**：`test-results/animation-lab/cast-v1/gpt/generation.json` 记录 Seedance **1.0 Fast**，单首帧 `anchor.png`，5秒，当时10积分。动作只要求细微呼吸、一次眨眼、发梢与尾轻微随动；无转身/走动。原图尾巴卷在身侧，尖不够清楚。生产225帧/9.375秒是后处理往返待机，不能反称生成了9秒原片；生产允许轻微线条变化，不等于已解决任意尾巴动作。

**摸头**：`pixverse-tail-p1/generation.json` 记录 **PixVerse V6 首尾帧**，1280×720、24fps、121帧/5.042秒，当时40积分，无音频。首图 `reference-audit/tail-anchor-builtin-v2-720.png` 与尾图 `keyframe-shy-v1-720.png`。这两张比待机anchor更明确地显示同一根尾向右下延伸、底部向左收尖；尾图把尖收到脚踝旁。正向完整片，没有倒放或截取。用户2026-10-30接受完整P1，历史抬尾/扫腿问题并未被修掉。它不是Seedance全能多图成功案例，也没有使用背面参考图。

因此较可信的工作假设是：待机因动作小而少重解释；P1因清楚、同构的首尾图降低中间路径的自由度。模型/入口也不同，不能把成功单独归因于某句提示词。两条片不足以估计稳定成功率。

## 最新 Cursor 交付

`jimeng-gpt-greeting-d1/generation.json`：Seedance2.0 mini，全能三图，5秒/720P，30积分；已标 `rejected-tail-geometry`，未替换生产，处理正确。接触表可见开场与收尾卷成粗弧，约2.49秒细尖侧伸清晰。它证明时序轮廓不稳定；正面小图不足以单独证明每个时点的根尖三维关系。纠错方案“先修图、停盲批”合理，但把Q0认定为唯一已证明根因仍是推断。

## 背面图有没有帮助

值得做，但**纯背面长发遮满尾根没有意义**。更有价值的是三分之四背侧结构参考：头发自然分到一边，不改服装结构，清楚显示翼根下方、骨盆后方的粗尾根；尾身连续变细、唯一尖在脚边。背面只承担连接说明，正面首帧决定成片朝向，不要求视频转身展示。不能为露根制造破裙、挖洞或把尾根接到裙摆；不可见结构可另做示意图供人审，不能伪装原作者设定。

先准备一张清晰正面/微侧开场图和同一套背侧图，核对尾长、鳞片、根的位置、衣装和角翼一致。优先复用P1已验首图作为实验基线；其与原idle头身/脚底差异仍需匹配，不直接替换待机。不要同时改首帧、模型、动作和参考数量。

### 最小对照，而非继续批量

1. 同一新动作/模型/时长，A只用P1清楚首图（若入口支持，配经审查的中性终点）；先检恢复与尾几何。
2. B只增加通过检查的背侧结构参考，其他尽量不变。全能参考和首尾帧入口若无法保留相同条件，就记录混杂，不能声称只测了背面图。
3. 动作先眨眼/轻点头，校准通过后加一次低位尾动；不是永久冻结尾巴。完整正向验收，不只检查最后一帧。
4. 对比身份、根尖连续性、动作完成与前后衔接；两次失败回静帧，不再自动跑其余32条。
