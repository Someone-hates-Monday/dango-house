# GPT 尾巴方向纠错方案（暂停视频）

2026-11-05。触发：`jimeng-gpt-greeting-d1` 片头仍把尾巴读反／粗细颠倒。  
**本阶段不继续批量生成视频**；先修静帧与参考分工，再开一条校准片。

## 1. 现象（greeting-D1 实测）

抽帧见 `test-results/animation-lab/gpt/jimeng-gpt-greeting-d1/review/`。

| 时点 | 观察 |
| --- | --- |
| 0.00–0.8s | 贴身侧一条粗鳞尾；靠脚一侧偏粗钝，靠身连接被发／裙挡得更细 → **片头即像「根尖对调」或「尖在上／粗在下」** |
| ~2.5s | 短暂甩出真正细尖（侧面），几何一度正确 |
| 收尾 | 又收回贴身粗钝团 |

结论：不是「偶尔动作夸张」，而是**开场锁定了错误厚度读法**；中段偶然做对也不能验收。与交接「前 1–2 秒定生死」一致 → **本条 D1 作废，不入生产**。

已验收真值对照：`public/community/gpt/idle.webp`、`public/video/gpt/idle-jimeng-v1.webm`、`pat-pixverse-p1.webm` —— 正确读法是：**骨盆侧粗根 → 右侧下弯 → 脚边唯一细尖**。

## 2. 根因（为何提示词 + 现有三图仍失败）

1. **开场图 Q0 本身歧义**  
   绿幕站姿里尾巴贴身卷成粗弧，末端收尖不够显眼，根被裙发挡。Seedance 以首帧外观为强先验，会把「显眼粗圆」当末端。

2. **结构图 QS 也会二次诱导**  
   现用 `05-tail-structure-34.png`：尾根仍半遮；弧线把**细尖抬高**，靠近地面一侧更粗。交接已写：可见度改善但**不称完整解剖证明**；前段仍反转应**暂停补清晰结构图**——本轮已触发该条件。

3. **文字读序压不过像素**  
   「上方是根不是尖」已写进 pack，但模型先抄 Q0 像素几何；加长负面词收益递减（交接：连续两次根尖错误回结构图，不再靠长负面加码）。

4. **参考角色冲突**  
   图1=Q0 负责构图 → 错误几何被当成开场真值；图3=QS 只「解释」却带高抬尖姿势 → 两种错误信号叠加。

## 3. 目标几何（验收一句）

任何人第一眼应能读出：

> **粗的那截在裙后／翼下连身体；细尖在膝下脚边；中间连续变细；无末端鳍。**

禁止：粗钝团贴脚当「尖」；细端插进腰侧当「根」；尖抬到腰／翼旁。

## 4. 方案（分阶段，先静帧）

### 阶段 0 — 冻结

- 暂停 GPT Q 即梦**视频**提交（含 greeting 重试与其余 P0）。  
- 保留已验收 idle／P1；greeting-D1 标 `rejected-tail-geometry`。  
- 现有 Q0／旧 QS **不再作为唯一结构真值**。

### 阶段 1 — 重做两张静帧（必须先过目视）

| 新资产 ID | 作用 | 硬性构图要求 |
| --- | --- | --- |
| **Q0-clear** | 唯一开场／构图首帧（绿幕 1280×720） | 正面或微 3/4；**尾根从骨盆后清楚露出一截粗段**（可略拨开下层裙／发）；尾身低位 C 弯；**唯一细尖停在脚／踝旁且明显细于根**；全身留边；不截尾 |
| **QS-clear** | 只解释解剖，**禁止当开场姿势** | 侧后或强 3/4 背侧；发拨开；**根完全可见在翼下骨盆**；单弧低位收到踝尖；**尖不得高于膝**；禁止大幅外展／高抬 S 弯 |

制作手段（任选，须可审计）：

1. 以内置生图／豆包静帧，严格按 `gpt-tail-structure-builtin-v1-prompt.txt` 精神改写（强调**低位尖、根全露**）。  
2. 或在合格社区姿上**人工修图**（擦开遮挡、加重根粗→尖细对比），记录来源与哈希。  
3. 可选第三张 **QS-annotate**（仅人审／必要时上传）：红点标 ROOT、蓝点标 TIP、沿尾画单向箭头；若即梦把文字烧进画面则**只留人审，不上传**。

**静帧验收清单（不过不进阶段 2）：**

- [ ] 根在骨盆／翼下，明显最粗  
- [ ] 尖在膝下脚边，明显最细且为唯一端点  
- [ ] 连续变细，无第二尖／鳍／叶片  
- [ ] QS-clear 尖不高过膝；不拿它当站姿开场  
- [ ] 与 idle.webp 读法一致（可并排贴对照条）

### 阶段 2 — 参考与提示词协议（有新静帧后再用）

上传默认改为：

1. **图1 = Q0-clear**（唯一开场）  
2. **图2 = Q1 idle 外观锚**（可继续用现 idle canonical）  
3. **图3 = QS-clear**（仅结构；提示写死「禁止复制其侧摆／抬尖」）  
4. **默认不传**旧 QS、00 拼图、04 多姿势、shy／happy（防表情／姿势串台）

提示词尾巴段改为「像素对齐」句式（示例，定稿时写入 pack 模板）：

```
开场必须与图1同一条尾的几何：图1中靠裙后／翼下的粗段=尾根；靠近脚的细端=唯一尾尖。
整段视频禁止把这两端对调，禁止把脚边粗钝团当成末端。
运动只允许根带动的低位毫米～厘米级位移；尾尖始终低于膝盖。
图3只用来确认「根粗尖细」，禁止学习图3里任何抬高的尖。
```

### 阶段 3 — 单条校准视频（仅 1 条）

- 动作：极简待机或 greeting 减配（几乎不动尾，只眨眼／轻点头），专测几何锁死。  
- 仍 5s／720P／Seedance mini；额度单发。  
- 验收：0.0–1.5s 根尖正确才继续；错则**停视频**，回到阶段 1 改静帧（不叠更长负面词）。  
- 通过后，再恢复 P0 批量；每条仍先审片头。

### 阶段 4 — 备选（阶段 3 仍连续失败时）
