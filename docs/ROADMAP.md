# 小屋愿望清单 / Roadmap

这是开发方向，不是交付日期承诺。欢迎通过 Issue 讨论具体需求与验收标准。  
These are directions, not delivery commitments. Discuss concrete needs and acceptance criteria in issues.

## 已可体验 / Available now

- 七位伙伴、小屋布置、自由桌宠、Dock 趴伏。Seven residents, room decoration, free pets, Dock resting.
- 群聊、私聊、称呼、好感、提醒和手动记忆。Group/private chat, relationship settings, affection, reminders, explicit memories.
- 本地群像、私聊欢迎和争宠；模型流式回复和形象工具。Scripted social scenes, private greetings/rivalry, streaming replies, avatar tools.
- 视频待机与部分独立互动，其余沿用图集和程序动作。Video idles and selected reactions; other actions use atlases/procedural motion.

## 优先完善 / Current priorities

- 补齐 Kimi、Grok 等独立互动，维持角色与尾巴结构一致。Expand interactions, especially Kimi/Grok, with consistent character and tail structure.
- 动作衔接、站起、恢复、落脚与位移验证。Improve transitions, recovery, foot contact, and movement verification.
- 绕行、遮挡与屏幕边缘表现。Improve navigation, overlap handling, and screen edges.
- 模型工具反馈、自然语言触发与服务兼容性。Improve tool feedback, natural-language triggers, and provider compatibility.
- UI 国际化与新手引导。Add UI localization and onboarding.

## 探索 / Exploration

分层 / Live2D、像素外观、语音、外部 Agent 联动、原创角色包。尚未实现，不属于当前下载版承诺能力。  
Layered/Live2D animation, pixel skins, voice, external agents, original character packs. Not implemented or promised capabilities of the current build.
