# v0.3.0：停靠、动作衔接与聊天立绘

## 使用

互动小屋顶部点「▁ 趴在任务栏」，或「连接与偏好 → 桌面上的陪伴方式 → 任务栏停靠」。托盘菜单也能切换。

Windows 版本停靠在显示器工作区底边，也就是通常的底部任务栏上缘。每人独立横向槽位，缓慢左右移动不超过12像素；鼠标靠近后站起，离开1.5秒后趴回。点头摸摸，点身体私聊，悬停显示投喂等按钮。趴姿的鼠标响应区域随视觉高度缩小，减少遮住桌面操作。多显示器按角色所属屏幕显示。自由桌宠的位置独立保留，切换不会重排用户保存的位置。

当前以底部任务栏为目标；第三方悬浮 Dock、任务栏自动隐藏时的露出位置以及左/右/顶部任务栏尚未自动识别。

## 素材与补画

DeepSeek、GPT、Gemini、Kimi 的趴姿来自已有 fywdy 动画图集。Claude、GLM、Grok 未找到同版本可直接用的趴姿，因此调用内置 imagegen 参考原形象补画，保留原图，新增 `public/repaired/dock-*-v1.png`。完整提示词 `dock-image-prompts.json`，原文件路径和 SHA256 在 `public/repaired/dock-manifest.json`。这是三张静态趴姿加连续局部运动与姿态过渡，不是已经补齐整套视频或真正的骨骼站起动作。

七位正常比例立绘来自 [shuaizenge/ai-girls](https://github.com/shuaizenge/ai-girls)，固定提交 `dcd69f5f4f2dff1a9c0031e82deb49e0fe949c76`，作者 ZipZipPipe [AI娘化合集](https://www.pixiv.net/artworks/148186519)。采用上游预览原字节（约279×500），逐项原出处、许可声明及校验在 `public/portraits/manifest.json` 和 `UPSTREAM-NOTICE.md`。群聊与私聊可切换正常比例/Q版。立绘只有本地呼吸、轻摆与情绪轻动效，不是 Live2D，也没有口型和肢体视频。

素材继续用于非商业原型。代码 MIT 不覆盖社区美术许可。作者分享/二创声明不等同于无条件商用许可。

## 动作与移动

- 六位非视频角色使用约40fps连续局部形变，保留已有表情/走路/挥手等序列，动作切换短过渡。GLM 保留黑狐原造型，局部运动为主。仍无法达到 DeepSeek 透明视频的逐帧丰富程度。
- 抚摸增加实际手部轻抚、触碰线与低头反应；不同角色有独立呼吸节奏、倾身方向和幅度。投喂使用对应食物及餐具，DeepSeek 大米饭仍使用专门的视频。
- DeepSeek 普通走路只循环原视频2.3–4.35秒段，排除4.45秒后的跌倒。停止后播放6.05–8.55秒恢复段。单独「跌倒与爬起」：摔倒→趴2.5秒→爬起→站稳，避免瞬间站起。视频切换时保留上一画面到下一段解码完成，短淡出衔接，不能替代缺失的真正过渡帧。
- 小屋与自由桌面按避让后的实际位置决定走路动作，停止位移就停止跑步。修复靠近、去家具等移动未同步桌面的原因；解决目标拥挤时反复瞬移到旁边的问题：先求不超过50%累计遮挡的目标，再以受限速度接近，拥挤时尝试小角度绕开。
