## 判断

CP-002、004、005 适合进入参考图制作；CP-003 先明确道具交接分支，作为高风险短试。CP-001 本次按 Cursor 最新工单保留已接入成片，不重做其三静帧，也不沿用 11 月 7 日快照覆盖 11 月 8 日状态。此次授权仅覆盖参考图，不提交视频、不消费即梦额度、不替换 public CG、不开启自动奖励。

原计划的主要问题是选项未落定：002 的站/半坐、膝上/桌上碗，003 的接过/推回/分享，以及跨帧书臂归属。给模型多个“或”容易让每张选不同分支。已具体化：

- **CP-002**：不带碗。S1 两人站在同一窗边沙发前，Claude 右手邀请、左手持打开的书；S2 两人都坐下、书移至 Claude 膝上；S3 合书、肩距缩短。鱼左 Claude 右。
- **CP-003**：只做“接过”，不混拒绝，不演吃一口。鱼双手端唯一碗 → 鱼两手加 Claude 右手共同支撑 → Claude 右手接稳、鱼收手。Claude 左侧始终保留书。生成首张出现蓝花白瓷碗，后续沿用其花纹，不临时换碗。
- **CP-004**：一本书、一条已随书存在的红书签。鱼凑近，书沿只挡部分下脸，眼睛保留；Claude 保持托书手与书页手的清晰归属。发现初版中间帧换托书手，另存 rejected，修正版单独复核。
- **CP-005**：鱼先靠近，Claude 从看书到察觉、短暂停顿再接纳；双方手留在自身区域。以视线、肩距和表情反差表现亲近，不把“主动”理解为必须拥抱/摸脸。

## 提示词与 Seedance 使用建议

[火山官方 Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh) 的检索可读段落强调明确人物与参考素材的对应，并提示多人+三视图可能复制人物；正文本轮抓取超时，不假称完整核读。社区 [Emily2040/seedance-2.0](https://github.com/Emily2040/seedance-2.0) 作为可参考的连续分段与回看工作流索引，不安装其技能、不把第三方宣称当模型保证。

本项目实际采用：每次只生成一张，两个角色锚各一张，加一张当前场景/前一姿态；图的角色显式区分。不用多人三视图拼图来“堆参考”，不靠负面词列表替代清楚的手位与单一动作。不把同人封面里的第三人、字幕、别场景作为身份真值。

静帧 S1/S2/S3 是**分镜/姿态参考**，不等于三个硬时序关键帧。即梦全能参考与首尾帧模式，以账户当前实际入口为准；不要只写“@图2 是第 2 秒”就声称时序被锁。短试优先 002/005，再 004，最后 003 的交接段。普通排队，**不用会员加速，不购买额度**。

## 交付与验收边界

按 Cursor 原约定目录落盘，每组 `stills/` 三张；见同目录 `stills-manifest.json` 与 `review.html`。每张记录本地 SHA256、实际尺寸、输入图 SHA、生成工具、完整提示词与复核备注。内置 image_gen；没有调用图片 API Key，没有使用视频模型。保留原生成文件，复制进项目；不强抠 CG 背景。

需要区分：单张身份/肢体初审、跨张相机/道具连续、视频过程、运行接入。本批可以做姿态参考，但任何相机、沙发/花纹、表情与物件细节漂移都要在 manifest 备注；不能因此承诺三帧无感插值。发现失败图留 rejected，不混在正式 S1/S2/S3 中。CP-003 尤其要逐帧核对交接手，CP-004 要核对抬书与书签过程。

给 Cursor：先打开审片页核对三图，再选择本条视频模式；一次只试一个短动作。实际成片的末帧决定下一段参考，不强迫模型用三张各自独立生成图直接拼长片。连续两次相同结构失败则简化分镜。新视频仍为 candidate，不因参考图通过就标 runtime/art accepted；无需重做已接受的 CP-001。
