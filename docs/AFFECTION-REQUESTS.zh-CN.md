# 亲近邀请与动作对白格式

0.5.0-alpha.12

小屋公开聊天中的「抱抱我」「牵手」「靠近一点」等明确邀请，由模型理解对象和意愿，接受时优先选择当前可用且符合情境的 CG。仍遵守相处模式、在场角色、自动播放开关、两分钟播放间隔与场景完成条件。没有匹配素材时用对白与已有动作回应，不假称播放了拥抱动画。现有 Claude 对用户片段是伸手靠近，不是完整拥抱；私聊仍使用自身动作工具，本次没有新增私聊 CG 工具。

所有实时对白统一指导为「（简短动作）说出口的话」，没有动作可直接说话。动作仅在开头，不在对白中间或末尾插入，不描述用户未经确认的反应。实际动画仍通过 intent 或工具执行，括号文字不能代替执行。

明确消除 Claude 每次放书、护书、合书的开场惯性；用户主动谈书或正在共读才提及。其他角色同样不强制反复提识别梗。表达版本升为 3，旧模型对白不再作为生成语气样本，可见历史及明确记忆保留。

这是模型选择与表达指引调整，不是固定关键词播放器；本次不改变冷却，也不承诺每次邀请都播放。单元测试和构建覆盖兼容性，真实模型输出仍需用户体验验证。
