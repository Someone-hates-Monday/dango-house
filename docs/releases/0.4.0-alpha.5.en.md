# 🍡 Dango House 0.4.0-alpha.5

A desktop home for AI companions: rest together on the Dock, chat, share a snack, and discover relationship moments through everyday interactions.

This milestone adds nine prerecorded relationship/POV CG clips with dialogue preludes and one shared overhead player per solo, pair or group event. Petting, feeding, praise, private chat and companion invitations stay in the everyday UI; recording controls live in local scripts. Lover mode, pair-affection preferences and automatic clips have separate gates.

This build fixes GPT changing into another dragon girl at the end of its idle loop. Sixteen stale PNGs from an earlier export had been appended to the video. Lossless trimming preserves all 225 correct frames and alpha; the exporter and full-loop checks now guard against this regression. UI and MCP versions follow the application version.

Download and run the Windows x64 portable EXE. Exit the old version before upgrading. Verify it against `SHA256SUMS.txt`. Existing chat and API settings use the same local user-data directory; do not post keys in issues or chats.

Offline scenes work out of the box; live AI chat needs your own API connection. Code and artwork have separate licenses; attribution and noncommercial terms remain in the NOTICE files. This is a preview, with mixed-DPI and live-provider combinations still subject to further testing.

Validation includes 114 tests, production build, stale-frame export regression, packaged full-loop/pause recovery and shared CG checks. See the [English closeout](https://github.com/Someone-hates-Monday/dango-house/blob/main/docs/PHASE-CLOSEOUT-2026-11-15.en.md).
