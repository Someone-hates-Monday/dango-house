# 🍡 团子小屋 0.4.0-alpha.5

让 AI 娘们住进桌面：趴在 Dock 上陪你，聊聊天、吃点东西，也会靠近彼此，在互动中留下关系瞬间。

本阶段加入九段预制关系与用户向 CG，配合前置对白自然触发；单人、双人或多人事件共用一份头顶播放器。日常界面保留摸头、投喂、夸奖、私聊和邀请伙伴，录视频用的演示控制留在本机脚本。恋人模式、百合偏好和自动短片偏好分别生效。

本版修复 GPT 待机末尾闪成另一名龙女的问题：导出目录残留的 16 帧旧图片被接入成片，现已无损移除，正常的 225 帧和透明通道保持不变；同时修复导出脚本并验证完整解码循环。界面与 MCP 版本号现在跟随应用版本。

下载 Windows x64 便携 EXE 后直接运行；升级时先退出旧版。校验值见随包的 `SHA256SUMS.txt`。本机聊天和 API 配置沿用原有用户数据目录，请不要把 API Key 发到 issue 或聊天中。

离线演示可以直接玩，真实 AI 聊天需自行连接 API。代码 MIT 与美术素材许可分别适用，署名及非商业约束见仓库 NOTICE。本包为预发行测试版，多屏混合 DPI 和所有真实 API 组合仍需持续验证。

验证：114 项测试、生产构建、残留帧导出回归、打包后的完整待机循环/暂停恢复与共享 CG 检查。阶段交接见 [中文收尾记录](https://github.com/Someone-hates-Monday/dango-house/blob/main/docs/PHASE-CLOSEOUT-2026-11-15.zh-CN.md)。
