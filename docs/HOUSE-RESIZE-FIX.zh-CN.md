# 小屋拉伸与点击恢复

0.5.0-alpha.14

发现两处可能导致拉伸后失去响应的风险：主进程尺寸通知写回请求尺寸，使限制/回传参与下一轮布局请求；拉伸时失焦或捕获丢失，没有完整清理状态。没有取得上次系统卡死的转储，因此不能断言全部症状都由此造成。

修复：尺寸通知只更新显示布局，不回写请求；待发请求合并，每 40ms 最多取最新一份，且同一时间只允许一个布局 IPC。尺寸达到边界后不再与规范化尺寸来回反馈。拉伸期间保留鼠标命中，释放、取消、失焦、捕获丢失均清理状态；无按键的移动不继续拉伸。小屋拖动同样补捕获丢失清理。

`scripts/verify-house-resize.mjs --packaged` 使用隔离存档，覆盖 480 次极端尺寸移动，以及释放、取消、失焦、捕获丢失；检查停止输入后原生尺寸稳定、按钮可点和 GPT 待机视频继续推进。源代码实测 480 次突发输入合并为一次原生尺寸更新。另回归原有小屋与窗口稳定检查；不修改用户存档。
