# 小屋愿望清单 / Roadmap

这是开发方向，不是交付日期承诺。欢迎通过 Issue 讨论具体需求与验收标准。  
These are directions, not delivery commitments. Discuss concrete needs and acceptance criteria in issues.

## 已可体验 / Available now

- 七位伙伴、小屋布置、自由桌宠、Dock 趴伏。Seven residents, room decoration, free pets, Dock resting.
- 群聊、私聊、称呼、好感、提醒和手动记忆。Group/private chat, relationship settings, affection, reminders, explicit memories.
- 本地群像、私聊欢迎和争宠；模型流式回复和形象工具。Scripted social scenes, private greetings/rivalry, streaming replies, avatar tools.
- 视频待机与部分独立互动，其余沿用图集和程序动作。Video idles and selected reactions; other actions use atlases/procedural motion.

## 优先完善 / Current priorities

- **当前首要顺序**：真正的在场编辑 → 可取消社交导演与共同事件记忆 → 三个完整试玩闭环 → 可选单脑场景生成。验收与 Cursor 任务见 [NEXT](CURSOR-COMPANIONSHIP-NEXT.zh-CN.md)。浏览/语音等扩展排在之后。
- **争宠闭环与百合亲密**：偏爱 streak、bond 阈值、双人亲密场景、亲密浓度；详见 [陪伴与百合规划](COMPANIONSHIP-YURI-PLAN.md)。
- **Agent 插件桥（可选）**：保留 App 本体；Cursor / Claude / Codex / REST harness 可安装 MCP 中转，详见 [AGENT-BRIDGE](AGENT-BRIDGE.md)。
- **小屋大脑 / 假扮 / 减员**：一把 Key 驱动全员人设、代言标注、今日在场；详见 [HANDOFF-HOUSE-BRAIN](HANDOFF-HOUSE-BRAIN.md)。
- **Agent 能干**：Playwright 可见浏览与真实推荐 URL；可选视觉证据适配器。见 [Agent 规划](AGENT-WATCH-PARTY-PLAN.md)。
- 补齐 Kimi、Grok 等独立互动，维持角色与尾巴结构一致。
- 动作衔接、站起、恢复、落脚与位移验证。
- 绕行、遮挡与屏幕边缘表现。
- 模型工具反馈、自然语言触发与服务兼容性。
- UI 国际化与新手引导。
