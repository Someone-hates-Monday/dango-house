# Roadmap

**Language / 语言 / 言語:** [简体中文](ROADMAP.zh-CN.md) · [English](ROADMAP.en.md) · [日本語](ROADMAP.ja.md)

Directions, not delivery dates. Discuss concrete needs and acceptance criteria in issues.

## Available now

- Seven residents, room decoration, free pets, Dock resting.
- Group/private chat, relationship settings, affection, reminders, explicit memories.
- Scripted social scenes, streaming replies, avatar tools.
- Video idles and selected reactions; other actions use atlases/procedural motion.

## Current priorities

- **Immediate order:** real presence editing, a cancellable social director and event memory, three complete playable loops, then optional one-backend scene generation. See [the next-stage contract](CURSOR-COMPANIONSHIP-NEXT.en.md). Broader browsing and voice work comes later.
- **Companionship & yuri loop:** favor streaks, bond thresholds, pair intimacy scenes, pairTone — see [COMPANIONSHIP-YURI-PLAN.md](COMPANIONSHIP-YURI-PLAN.md).
- **Optional Agent plugin bridge:** keep the desktop app; installable MCP/REST adapters for Cursor / Claude / Codex — see [AGENT-BRIDGE.md](AGENT-BRIDGE.md).
- **House brain / cast:** one key for all personas, via badges, today’s-cast presets — see [HANDOFF-HOUSE-BRAIN.md](HANDOFF-HOUSE-BRAIN.md).
- **Practical agents:** visible Playwright browse with verified recommendation URLs; optional vision evidence adapter — see [AGENT-WATCH-PARTY-PLAN.md](AGENT-WATCH-PARTY-PLAN.md).
- Expand interactions (especially Kimi/Grok) with consistent structure.
- Improve transitions, recovery, foot contact, and movement.
- Improve navigation, overlap, and screen edges.
- Tool feedback, NL triggers, provider compatibility.
- UI localization and onboarding.
