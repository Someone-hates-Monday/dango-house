# Persona lock · interaction · shot & activity playbook

[中文全文（制作手册）](CG-PERSONA-SHOT-INTERACTION-PLAYBOOK.zh-CN.md)

Date: 2026-11-04. Research/process only — does not authorize restarting image or video generation.

Operational pipeline beyond high-level control principles:

1. **Identity Sheet** — visual anchors, drift bans, personality axes, do/don’t, prop ownership; blind recognition test before any beat design.  
2. **Why This Beat** — one motive card derived from persona + `socialProfiles`.  
3. **Activity mode** — `WATCH` / `BEAT_WAIT` / `CHOICE_2` / `PARALLEL_Q` / `REACT_SIDE`.  
4. **Beat sheet** — B1 setup → B2 single visible action → B3 reaction + hold; user wait points explicit.  
5. **Shot nails** — gaze vectors, limb ownership, expression completion asymmetry.  
6. **Model constraint pack** — layered prompt + stills before I2V / Jimeng first–last / control video.  
7. **Fail downward** — drop contact → gaze play → single POV → stills + in-app Q motion.

Full tables, seven-character lock summary, and copy-paste worksheets are in the Chinese document.
