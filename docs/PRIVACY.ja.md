# プライバシー

**Language / 语言 / 言語:** [简体中文](PRIVACY.zh-CN.md) · [English](PRIVACY.en.md) · [日本語](PRIVACY.ja.md)

団子小屋はチャット・メモリー・関係設定・表示言語を、この Windows ユーザーのプロファイル（`%APPDATA%/Qiting`）に保存します。API Key は Electron の `safeStorage` で暗号化し、チャットへの入力は不要です。

本番モデルへは、選んだサービスのへ、現在のチャンネル文脈・キャラ指示・関連する小屋状態が送られます。観影メディアは、明示のクラウド視覚経路を後から有効にしない限りローカルキャッシュに留まります。

群聊の消去、メモリー削除、Key 削除は「接続と設定」から行えます。Issue やスクショに Key を載せないでください。
