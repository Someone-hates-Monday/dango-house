# 同人搜集 · 统一人设 · CG／日常动作分流

[English index](FANWORK-PERSONA-AND-CG-CATALOG.en.md) · 制作细则：[Playbook](CG-PERSONA-SHOT-INTERACTION-PLAYBOOK.zh-CN.md) · 表演调研：[ACTING](CG-ACTING-AND-POV-RESEARCH.zh-CN.md)

日期：2026-11-04。**只做索引与分类；不恢复生图／视频，不改生产素材，除非用户另行指示。**

复核说明：本文「正典」指**项目拟采用版本**，不证明社区统一共识；「高频／最受欢迎」在没有逐作品统计前均为定性候选。七张合成摘要仍待锚图与逐字段证据核对，不等于已批准身份卡。正常比例的参考图本身不证明角色年龄。制作与验收按 [制作契约](CG-PRODUCTION-CONTRACT.zh-CN.md) 执行。

**2026-11-04 搜集续：** 已开四层身份卡草稿与 API 复核播放量台账 → [cg-production/identity/](cg-production/identity/README.zh-CN.md) · [evidence-ledger.json](cg-production/evidence-ledger.json)。摘要表仍不能替代身份卡；台账条目多为 `meta-only`，有可播原片后再补时间码。

目的：从视频站与社区同人中，以**最受欢迎且可交叉核对**的版本统一人设，筛掉冲突变体；再把常见互动分成：

| 层 | 素材体型 | 用途 |
| --- | --- | --- |
| **关系 CG** | **成年体／正常比例立绘**（ZipZipPipe《AI娘化》系） | 留座、表白级靠近、对用户留饭高潮等；稀缺升格 |
| **日常举止** | Q 版桌宠／Dock／程序动作（可含已有 fywdy／109 段） | 挥手、吃饭、摸头、轻微吃醋气泡；丰富日常，**不升格为 CG** |

**硬规则**：CG 参考与成片锚点**只用成年体**，不用 Q 版当 CG 首帧／尾帧；Q 版互动可保留并扩充日常动作库。

### 正式制作口径（已确认）

社区 UP 成片**不入库、不直接当 CG／桌宠素材**。用途仅限：

1. **互动／动作／表情参考** — 谁先动、视线、反差、停顿、吃醋旁支等节拍；  
2. **参考图／参考视频** — 给即梦全能参考、Wan Animate／Fun Control、LivePortrait 等当**表演或运镜驱动**，不当最终画面；  
3. **自己生成** — 首尾帧与成片必须落在**团子小屋房间／Dock／成年体锚点**上。

原因：他人视频的场景、构图、光色、镜头比例与小屋固定房间背景很难一致；硬抠或直接播会穿帮。流程固定为：

`看同人学节拍 → 用本仓成年体立绘钉静帧（小屋背景）→ 可选参考视频只驱动动作／表情 → 自有成片验收入库`

授权清楚的静帧（如 ZipZipPipe 开放再创作声明下的立绘）可作身份锚点；互动短剧成片仍只当参考。

## 3. 互动题材库 → CG／日常分流

图例：

- **CG-A**：可直接按成年体分镜制作（结构简单、单接触或纯视线）  
- **CG-B**：题材好，但需额外生成／控制轨（多臂、道具传递、长位移）  
- **DAILY**：不进 CG；Q 版／程序／短气泡丰富日常  
- **SKIP**：与正典或合规冲突，不收录

### 3.1 角色×角色（百合／群像）

| 题材（社区高频） | 代表线索 | 分流 | 说明 |
| --- | --- | --- | --- |
| 窗边留座／并肩 | 本仓 seat-share；大小姐专属座位 | **CG-A** | 成年体三拍；已有离线剧情可升格 |
| Claude 整理大鱼发饰／发丝 | ACTING 定演法；黑猫勇者甜向 | **CG-B** | 接触结构难，须静帧过关再视频 |
| Claude 表白／靠近 | 戛然而纸表白篇；蒸馏模型 PV | **CG-A/B** | 近景视线戏可 A；拥抱 B |
| 鲸尾×龙尾缠绕特写 | X／同人图梗（待补具体原页） | **CG-B** | 尾根、遮挡与两种尾型连续性复杂，不能按低结构难度安排 |
| GPT 嘴硬留座给鱼 | 女同事吗；本仓龙娘线 | **CG-A** | 单人＋鱼入画或双人站位 |
| GPT 吃醋旁观 Claude×鱼 | 「gpt心碎了」婚礼图支线 | **DAILY** 或短 **REACT** | 不宜抢主 CG |
| 星猫×黑狐友情价抱抱 | 本仓 star-fox；账本 | **CG-B** | 真正拥抱需四臂结构验收；降为无接触视线戏才可 A |
| Grok 逗 GPT | 戛然而纸 Grok×GPT | **CG-A** | 靠近＋无奈脸；少肢体缠绕 |
| 合租起床／抢饭／一碗限制 | 冬冰中转站公寓 | **DAILY** | 适合 Q 版群像气泡，不作稀缺 CG |
| 伪装成 Claude 被抓 | 法棍猫等运营向 | **DAILY** 彩蛋 | 卫衣鱼皮肤向；默认 CG 不用 |
| 采购布置房间堆米 | 法棍猫 | **DAILY** | 道具多，程序布置更合适 |
| 暖阳相拥小憩 | 法棍猫标题向 | **CG-B** | 四臂归属重；降级为依偎近景可 A |
| 竞技场／对战／量化战士 OP | 多作者 | **SKIP**／宣传外 | 非小屋生活主轴 |
| 音乐 PV／翻唱 | 暗影神秘使等 | **SKIP** 作 CG | 可外链欣赏，不入库动作 |
