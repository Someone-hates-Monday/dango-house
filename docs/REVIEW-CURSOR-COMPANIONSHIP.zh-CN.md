## 必修问题（均有运行复现）

### P1：剧情尚未完成就写成共同记忆并发关系奖励

`electron/engine.ts` 的 `companion-story` 在安排 `beats` 后立即 `bumpBond` 与 `pushCompanionEvent`；`playYuri` 也在播放前写 `pair-scene`。触发留座后立刻停止，仍留下“留座已发生”的事件和关系奖励，后续还能选到“又一次”分支。

这直接阻断自动 CG：若据此解锁，就会出现戏没演完、甚至被取消，高潮 CG 却已经可播。`perform` 中对接近对象的无条件关系增长也必须收拢，否则只延后故事奖励仍会留下绕路。

**要求**：完成/取消结果由导演统一发出，且事件与奖励按场景实例 ID 原子、幂等提交；失败、取消、参与者缺席不得提交成功结果。

### P1：SceneDirector 没有真正接管运行队列

类中有 `due`、`clear`、`dropMissing`、`onComplete`，但引擎依旧直接消费 `this.scene`；只对新故事调用 `schedule`，不消费导演结果。旧群像、争宠、模型伙伴回应等直接改数组，`freezeRoom` 也只清数组。

复现：开始用户点播的留座，再摸 DeepSeek 三次；旧争宠台词在约一秒后插入，并改写正在主演的 Claude 动作，绕过了 user > reaction > idle 的优先级。

**要求**：单一调度入口和单一执行源；所有用户短剧、旧群像/双人、反应、空闲戏都经同一个生命周期。替换/停止/缺席/静音/专注/DND 清理实际作业，而不是仅清表面数组。

### P1：缺席约束只接在部分 UI/动作上

`perform` 没有检查操作者或角色目标的在场状态。直接 action / MCP / 模型回调仍可让缺席 Grok 获得动作，或让 Claude 靠近缺席 DeepSeek 并增加 bond。`feed`、`companion-visit`、`play-clip`、`praise` 等也需要统一审计，不能只补一个 UI 按钮。

**要求**：在统一引擎/工具入口验证操作者、角色目标和当前作业身份；安静与缺席分开处理。对缺席者的私聊应只显示请回入口，不能通过投喂或工具绕过。已有 Agent/Bridge 回调也必须受同一约束。

### P1：可选剧情模型的提示与取消没有接通

`companion-story` 把 `storyLlmPrompt(plan)` 传入 `generate`，但实际 `generateReply` 的 `_input` 被忽略，只从 `state.messages` 组消息。受控 HTTP fixture 证明请求体里没有“极短旁白”指令，模型实际上在接着旧群聊回答。

该路径还把空函数当成 `act` 传下去，配置允许工具时仍会提供形象工具，可能进入多轮工具请求，违背“一次无动作旁白”的预算。它的 AbortController 不属于 `stop()` 的控制器，停止或退场后请求仍能回来插入 system notice。

**要求**：专用、单次、禁工具的旁白/场景接口，真正传递提示；与作业取消 token 绑定，响应提交前再核对场景实例和参与者。或先禁用此选项，保留离线剧情，不用无效 API 消耗冒充智能增强。

### P2：私聊返回不幂等，第一次也会被当作“又一次”

同一轮 `private-open` 后调用两次 `private-return` 会写两条返回记忆。原测试用 `>= count` 允许重复，却注释为幂等。返回台词检测到刚写入的 `chose-companion` 就选“第二次/又回来”，因此首次正常返回也会走复访台词。

**要求**：每位角色/每次真实私聊访问有独立实例和一次性结束标记；关闭源统一。试玩“返回”要有显式演示实例，不能削弱真实会话幂等。复访依据应是之前已完成的访问，而非这次刚打开的事件。

1. 取消不提交共同完成与关系奖励。
2. 不给缺席操作者表演。
3. 不与缺席目标增长关系。
4. 停止会取消剧情模型且屏蔽晚到输出。

## 下一轮交付顺序

1. **生命周期修正**：导演单一执行源、参与者入口验证、取消、完成回执与奖励/记忆幂等。更新当前把“已排队”当“完成”的测试与交接表述。
2. **模型/私聊修正**：真实单次提示、禁工具、取消与来源；私聊实例结束幂等和真正复访分支。若无法完成，明确禁用模型增强。
3. **编排与 CG 自动触发**：上述全部通过后，再按 `CG-MOMENTS` 接完成事件。动作步骤按到达/可用片段的完成或超时边界衔接，而不是统一每三秒切姿势；不重写或删掉现有 109 段播放系统。

CG 是情绪爆点的加分项，不是掩盖日常导演缺陷的过场动画。宣传可用试映素材，但必须标“剧情演出/试作”；现阶段不要宣称“七人自主共同生活已经完整实现”。
