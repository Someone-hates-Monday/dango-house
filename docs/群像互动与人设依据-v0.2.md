# 团子小屋 v0.2：七人群像

2026-10-28。角色身份与 API 服务分离，GLM 或 Kimi 都能驱动任意已入住角色。

## 关系与场景

- Claude → DeepSeek：用户指定喜欢大鱼；认真关心、留座，带一点大小姐的笨拙。默认方向熟悉度 65，反向独立计算。
- GPT → DeepSeek：嘴硬留座、饭搭子；Grok → GPT：主动靠近，善意逗前辈。
- Gemini ↔ GLM：星猫好奇、黑狐算账，点心的友情优惠。小屋原创搭档，不声称是社区统一 CP。
- Kimi → Claude：陪读、书签；Kimi / Gemini / Grok 一起编故事。陪读性格是本应用演绎。
- 七段可选剧情覆盖七位，另有全员问候、下午茶和轻度争宠。动作、靠近、气泡在小屋和桌面同步。

对白均为原创短场景；未复制视频片段、对白、配音或音乐。

## 实现与边界

`src/shared/social.ts` 集中管理关系方向、来源与剧情。关系以 `from>to` 保存，靠近增加该方向熟悉度。闲置时轮播本地剧情，不收费；免打扰、专注或忙碌时不启动。

模型可通过白名单工具 `perform_action` 控制自己的形象，限制坐标、持续时间及次数；不具有执行系统命令的能力。私聊只发送该频道消息与共同记忆，另附用户关系与伙伴熟悉度。

六位使用 fywdy 逐帧 Q 版图集。Claude 默认用直立读书行，避免原待机行缩扁。GLM 保留 CrossPet 黑狐造型，使用原表情差分和局部运动，不混入其他版本。

投喂、抚摸是现有开心/害羞姿态与气泡、爱心的组合，没有专用咀嚼/抚摸骨骼动画。完整 Live2D、正常比例/像素外观、碰撞寻路尚未实现。美术来源、校验值和非商业许可保留在 public 下的两个资源目录。
