# 对话驱动 CG：私聊、群聊与同伴交流

版本：0.5.0-alpha.13。

## 怎么使用

开启「互动后的剧情短片」，参与者在场。对用户的亲密片段需要恋爱相处模式；女孩之间的亲密片段需要开启贴贴。私聊还需启用 API 形象工具。

现在可以在 Claude 私聊说「能抱抱我吗」，或者在群聊邀请 Claude 和 DeepSeek 靠在一起休息。她们自主交流中自然出现的亲近也可选择 CG。模型决定是否接受及是否有匹配素材；不是固定关键词播放器。现有 Claude 对用户素材是伸手靠近，不是完整拥抱视频。

## 执行流程

私聊提供 `request_cg({asset})` 工具，只能选择自己参与的单人、面向用户的现有片段。工具返回 queued 或 blocked，排队不等于已经播放。工具不把私聊转成公开的同伴剧情，也不外传私聊正文。

模型漏调工具时，使用同一模型对当前输入与已生成回复做一次有界语义判断，超时 6.5 秒。它只能从合适候选目录选择或返回 null。普通闲聊和拒绝不应触发。不使用关键词强制代替模型意愿。

公开和同伴交流在场景计划中提交 `cgAsset`，并用 `cgRequested` 表达是否形成了适合片段的亲近情节。漏填时有界修正；完整计划未选择 CG 时可做一次语义选择，候选必须符合本轮对象、设置，且参与者已在计划中发言。自主交流也适用。动作和接话结束后才播放一份共享 CG。

私聊回复完成后安排短暂表情铺垫，再由同一场景队列播放。请求期间取消、API 失败或角色不在场，不补播。冷却从实际开始播放计时，仍为两分钟全局间隔。播放前重新检查免打扰、专注、自动播放、相处模式、参与者、桌宠可见性与当前播放器。冷却或设置拦截会给出原因，私聊原因留在私聊；公共场景的播放拦截在公共记录提示。

无匹配素材由角色自然说明；不会凭空生成片段。工具关闭时不偷偷另起私聊 CG 决策。语义检查可能增加一次模型调用与少量等待、费用；没有后台高频轮询或无限重试。可选判断失败时保留原回复。

## 验证与边界

- 169 项测试：私聊完成后排队、取消不补播、设置拦截、角色/对象限制、两类 API 工具流，以及私聊和自主交流漏选的语义补选。
- `scripts/verify-private-cg.mjs --packaged`：隔离存档、本地模拟 API，经真实主进程工具回调与渲染器，检查视频实际解码播放、单播放器、私聊隔离和可见拦截原因。
- 回归公开/私聊邀请、同伴到达接话、共享 CG 与各自气泡。测试无需用户密钥，不修改真实存档。
- 模型语义判断和网络服务仍可能失败；不承诺每次请求都有片段，也不把模拟 API 验收称作真实服务质量验收。

入口：`electron/avatar-tool.ts`、`electron/provider.ts`、`electron/engine.ts`、`electron/main.ts`、`src/shared/house-events.ts`。
